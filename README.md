# Онлайн-школа «Самый умный»

Минимальный веб-сервис онлайн-школы для дипломного проекта с интеграцией заявок:

- страницы: главная, о школе, предметы, форматы обучения, запись, FAQ, контакты и политика данных;
- форма записи сохраняется в SQLite;
- при настройке переменных окружения заявка отправляется в Telegram.

## Что улучшено в интерфейсе и структуре

- сайт переориентирован с визитки репетитора на полноценную онлайн-школу «Самый умный»;
- добавлены разделы «О школе», «Предметы», «Форматы», FAQ и политика обработки данных;
- главная страница стала лендингом: первый экран, цели обучения, предметы, форматы, этапы обучения и форма заявки;
- добавлены возрастные направления 6–9, 10–14 и 15–18 лет;
- каталог предметов показывает возраст, формат занятий и цель обучения;
- добавлены блоки преподавателей-заглушек, абонементов, результатов и будущего личного кабинета;
- визуальный стиль обновлён в светлой образовательной палитре с мягкими синими, зелёными и жёлтыми акцентами;
- используются адаптивные карточки, крупные кнопки, мягкие тени, декоративные фигуры и веб-шрифт Manrope.

## Технологии проекта

- Frontend: HTML5, CSS3, Jinja-шаблоны;
- Backend: Python + Flask;
- Database: SQLite;
- Communication: Telegram Bot API;
- Infrastructure в перспективе: Ubuntu Server 24.04, Docker, Nginx, Asterisk.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app/app.py
```

Откройте `http://127.0.0.1:5000`.

## Переменные окружения

- `FLASK_SECRET_KEY` — секрет Flask;
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_CHAT_ID` — ID чата для заявок.
