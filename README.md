# Reper Site

Минимальный веб-сайт репетитора для дипломного проекта с интеграцией заявок:

- страницы: главная, запись, контакты;
- форма записи сохраняется в SQLite;
- при настройке переменных окружения заявка отправляется в Telegram.

## Что улучшено в интерфейсе

- современный градиентный фон и декоративные световые элементы;
- подключён веб-шрифт Inter;
- обновлены карточки, кнопки, скругления, тени и hover-эффекты;
- главная страница оформлена как презентационный лендинг (hero, услуги, преимущества, формат);
- страница записи получила более удобную и визуально аккуратную форму;
- страница контактов оформлена как полноценный контактный блок;
- добавлена адаптивность под телефон и ноутбук.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app/app.py
```

Откройте `http://127.0.0.1:5000`.

## Переменные окружения

- `FLASK_SECRET_KEY` — секрет Flask;
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_CHAT_ID` — ID чата для заявок.
