Политика обработки персональных данных

Этот раздел нужен для формы записи, где пользователь указывает имя, контакт, возраст ученика, предмет и удобное время.

Какие данные собираются

Сайт сохраняет имя, телефон или Telegram, возраст ученика, выбранный предмет, удобное время и комментарий к заявке.

Зачем нужны данные

Данные используются только для связи по заявке, подбора формата обучения и передачи заявки администратору онлайн-школы.

Где хранятся данные

В текущей версии заявки сохраняются в локальной SQLite-базе приложения. При настройке Telegram Bot API данные также отправляются администратору в Telegram-чат.

Ограничение доступа

Доступ к заявкам должен быть только у администратора системы. В дипломном проекте этот раздел демонстрирует базовый подход к обработке данных.
